# Прозрение — редизайн сайта глазной клиники

Концепт редизайна сайта глазной клиники «Прозрение» (Махачкала, prozrenie-clinic.ru). Статичные HTML-прототипы.

## Что внутри

| Путь | Что это |
|---|---|
| `index.html` | Обзор всех вариантов дизайна |
| `v1-tochnost.html`, `v2-zabota.html`, `v3-katarakta.html` | Первые три направления (главная «Точность», «Забота», лендинг катаракты) |
| `sait/` | Выбранный вариант «Точность», развитый в сайт |
| `sait/index.html` | Главная |
| `sait/index-v2.html` | Вторая главная «Спокойствие»: фото под «шторкой», день в клинике, сценарий операции |
| `sait/*.html` | Лазерная коррекция, катаракта, детская офтальмология, диагностика, врачи, профиль врача, цены, отзывы, о клинике |

## Как посмотреть

Онлайн: https://prozreniye.vercel.app (обзор вариантов), https://prozreniye.vercel.app/sait/ (сайт), https://prozreniye.vercel.app/sait/index-v2.html (вторая главная).

Локально:

```bash
python3 -m http.server 4321
```

Открыть http://localhost:4321 — обзор вариантов, http://localhost:4321/sait/ — сайт.

Клавиша **G** на страницах сайта показывает 12-колоночную сетку, **Shift+G** — базовую линию 8px. Параметр `?grid` в адресе включает сетку сразу.

## Как редактировать сайт

Страницы в `sait/` собираются из исходников:

- `sait/src/*.html` — содержимое страниц
- `sait/partials/` — общие шапка, подвал, блок записи
- `sait/assets/site.css` — дизайн-система (сетка, шрифты, отступы, компоненты), `home-v2.css` — стили второй главной

После правок:

```bash
cd sait && python3 build.py
```

Публикация на Vercel (из корня проекта):

```bash
npx vercel@latest deploy --prod
```

## Важно

- Это демонстрационный прототип: формы записи ничего не отправляют.
- Фото врачей и клиники загружаются с текущего сайта клиники, стоковые — с Unsplash (помечены как иллюстративные). Нужен интернет.
- Факты, цены и биографии взяты с текущего сайта клиники.
